# Daygo

**简体中文** · [English](README.en.md)

**让工作自然发生，让记录自动完成。**

> **macOS 源码体验版** · 自带你的 AI Provider · 数据默认保存在本机

Daygo 把离散屏幕截图、AI 分析和工作复盘放进一个隐私优先、本地优先的桌面应用：按时间整理活动卡片，回看一天的工作，并从已有记录观察一周的节奏。

不用启动计时器，也不用在一天结束时努力回想“我刚才都做了什么”。打开 Daygo，你会看到自己的工作如何展开：写代码、查资料、开会、沟通、设计，以及在任务之间切换的真实节奏。

## 为什么用 Daygo

- **自动记录，而不是手动打卡**：离散截图在后台完成，活动会按时间、标题、摘要和分类整理成卡片。
- **保留工作的上下文**：展开时间线卡片即可回看关联画面，快速找回当时正在处理的问题。
- **一键生成每日复盘**：从当日活动生成摘要，结合日记与目标，沉淀真正属于你的工作记录。
- **看见一周的节奏**：按周查看记录时长、专注时长、分类占比、每日分布与趋势。
- **结果始终可控**：可以修改标题、摘要和分类，删除不需要的卡片，或重新处理一段记录。
- **使用你自己的 AI**：支持 OpenAI Chat Completions、OpenAI Responses 和 Anthropic 兼容协议，可为同一 Provider 配置多个模型，并设置有序回退链。

## 为隐私而设计

Daygo 处理的是非常私密的数据，因此隐私不是一个附加选项，而是产品边界。

- 截图、时间线、日记和数据库默认保存在本机。
- Daygo 没有自有后端，也不会替你选择默认 AI Provider。
- 屏幕数据只会发送给你明确配置的 Provider；也可以连接兼容协议的本地模型。
- 可以屏蔽指定应用；被屏蔽应用位于前台时，Daygo 使用脱敏占位帧。
- API Key 只存入系统凭据存储，前端无法读取密钥原文。
- 分析与崩溃上报默认关闭，并禁止收集屏幕内容、窗口标题、文件路径、API Key 或 LLM 请求内容。

macOS 上的数据位于：

```text
~/Library/Application Support/Daygo/
```

数据库、录制分段与备份都集中在这里；API Key 保存在系统钥匙串中。完整边界见[隐私与安全设计](docs/07-privacy-security.md)。

## 开始体验

Daygo 当前以 macOS 14 或更高版本的源码体验版提供。你需要 Go 1.25+、Node.js 20.19+（或 22.12+）、npm 和 Xcode Command Line Tools。

```bash
git clone https://github.com/Jwz-git/Daygo.git
cd Daygo
./scripts/dev.sh
```

首次启动后：

1. 按系统提示授予屏幕录制权限。
2. 在设置中添加 AI Provider、API Key 和模型，并运行连接测试。
3. 设置截图间隔、屏蔽应用、界面语言和存储上限。
4. 开始录制；完成首批分析后，时间线会自动出现。

> macOS 可能要求重启应用后，新的屏幕录制权限才会生效。

## 你掌握哪些控制权

- 随时开始、暂停或停止记录。
- 使用浅色、深色或跟随系统主题，并在中文和英文间切换。
- 设置录制数据的磁盘上限；清理以完整分段为单位进行，不会删除正在写入的数据。
- 查看录制空间占用和不包含敏感内容的运行诊断。
- 使用自动检查点、备份保留与损坏恢复机制保护本地数据库。

## 面向贡献者

Daygo 使用 Go、Wails、Vue 3、TypeScript、Pinia 和 SQLite。Go Core 持有业务逻辑与唯一数据库写入权；系统能力通过平台端口隔离，前端只通过生成的 Wails 绑定访问 Go。

```text
Vue 3 + TypeScript
        ↓ Wails bindings
Go services and foundation
        ↓ platform ports
macOS native adapters
```

提交前运行完整门禁：

```bash
./scripts/gate.sh
```

门禁会引导生成前端产物和 Wails 绑定，并执行 Go 构建、测试、静态检查、前端类型检查、单元测试、生产构建与文档检查。
