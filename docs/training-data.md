# 本地训练数据采集工作流

入口：设置 → AI 服务 → 训练样本。实现决策见 [本地采集与审阅](decisions/training-sample-collection.md)。
此功能服务于开发者采集训练候选；不代表 Qwen 模型已微调或质量已通过验收。

## 使用步骤

1. 配好正常分析使用的 Provider。打开训练样本页面，确认本地保存授权，设置 1–480 分钟和 1–100 条上限。
2. 开始采集后继续使用 Daygo。收集的是授权期间实际发起的转录 / 首轮卡片请求，包括后台补处理的历史批次，
   不是重新截屏，也不限制为截图发生于本次会话；范围以请求发生时刻为准。只纠错的后续卡片请求不采集。
3. 选中样本，点击图片查看原尺寸，检查完整提示词、原始候选和历史教师答案。普通日志不含这些内容。
4. 修改训练标签，分别确认内容质量和整份样本的隐私审阅。“保存”保留草稿；“接受标签”运行 Schema / 领域校验；
   敏感样本应拒绝并删除。首版不提供自动匿名化或图片编辑，修改标签不会删除原始答案中的敏感内容。
5. 如需更强教师，选择已保存的 Provider 和其模型，确认发送完整输入，再点击单次重新标注。
   每个样本最多四次教师答案；使用同一输入与 Schema，不回退、不改写时间线，可能有费用。
   教师答案保留历史并清空隐私和质量批准，需要重新审阅。模型输出仍是数据。
6. 点击导出：当前列表中最近的最多 100 条“已接受且隐私已确认”样本写为 ZIP；无自动上传。
   打开导出文件夹后人工交付。不要将真实样本包提交 Git。
7. 重启后采集关闭，已保存样本与审阅结果保留。停止采集丢弃排队和尚未完成的采集结果，
   正在提交的文件可能完成；不取消正常推理。页面每 5 秒刷新状态，样本列表按事件刷新。

## 文件与训练格式

目录为业务数据库同目录的 `training/`（不跟随录制目录迁移）：

- `source-group`：随机安装来源组，整个来源组应划入同一个训练 / 验证 / 测试集合。
- `samples/<id>.json`：版本化样本，包含实际图片字节、图片摘要、提示词 / Schema 摘要、输入上下文、
  代码版本、请求 / 实际模型、协议、原始候选、教师历史、修订标签与审核版本。图片为 JSON base64。
- `exports/<id>.zip`：独立导出副本，含 `train.json`、`images/`、`samples/` 和格式说明。

`train.json` 是 Qwen 风格记录数组，`conversations` 含 human / gpt，human 中的 `<image>` 与
`image` 相对路径数组顺序一致，纯文本卡片样本没有 image 字段。gpt 使用人工确认的 Label。
导出模板在原始 prompt 与图片标记后附加输出 JSON schema；精确原始输入仍保存在 samples。
为防止 Qwen 把普通文本误当作媒体占位符，含字面量 `<image>` / `<video>` 的提示词或标签暂拒绝导出，
不静默删改原文。图片限 PNG / JPEG。正式训练仍须验证所选框架的 chat template 与图像 token 掩码。
可先执行 `python3 scripts/training/validate_dataset.py /path/to/export.zip`；该命令只读 ZIP，
检查审核状态、训练答案配对、图片摘要和媒体标记数量，只输出计数，不打印正文。
这是格式加载检查，不等于训练框架 tokenization 或微调成功。

保留 `group_id`，不要逐行随机拆分；同一安装来源组跨采集会话仍相同。此分组较粗，后续可经数据治理验证再细分。

记录的是应用级请求与配置的输出预算，不是 HTTP 原文；不记录 endpoint、Authorization 或密钥。
返回的密钥回显在进入样本前脱敏；这不会改变生产分析收到的结果。代码版本从 Go build info 读取，
缺失时明确记录 development，不能据此声称权重 / 代码完全可复现。未微调的模型是候选标签来源，不是真值。

## 限额与一致性

单会话最多 100 个已预留样本、累计输入 512 MiB；队列长度 2，超限或写失败有计数，
不把训练采集错误传播给正常分析。单样本 JSON 上限 32 MiB，整个 training 文件目录约束为 1 GiB，
包含导出副本；保守估算不足时导出拒绝。样本修改采用 revision 比较，过期审核 / 教师写入返回 conflict。
相同会话、任务、上下文、图片、提示词及 Schema 的重复成功请求去重；失败请求释放预留 ID，后续成功可采集。

默认不开启网络监听，不建立第二个数据库连接。文件为 0600、目录创建为 0700；由唯一可写宿主管理。
训练副本不随原始录制清理，删除源样本也不删除既有导出包；空间不足时由用户清理不再需要的导出文件。
导出原始候选和教师历史是为了追溯，因此隐私确认覆盖整个样本，而非只有最终标签。
