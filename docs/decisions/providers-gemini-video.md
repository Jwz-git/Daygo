# Gemini 原生协议与原始视频分段输入

Gemini 使用 Developer API 的 `generateContent`、`models` 和 API Key，默认地址为
`https://generativelanguage.googleapis.com/v1beta`。模型列表筛选可调用 `generateContent`
的模型。目标模型的视频输入和结构化输出能力须用实际请求验证。

时间线默认向 Gemini 条目发送符合条件的原始 MP4 分段。每个请求内联一个分段，最多 8 MiB，
无需转码、重新合成或创建服务商端文件对象。只接受已收尾、单视频轨、非碎片化的 MP4，
且本批必须包含该文件全部已提交、未删除的截图，索引从 0 连续到最后一帧。
媒体适配器在录制根目录内打开文件，以 MP4 的样本表验证本次将发送的同一份字节。
有额外样本、缺口、跨批次、格式不符或超限时走截图。已有隐私脱敏在捕获写入时执行，
分析只读取这些已提交的截图或包含它们的完整分段。

两种请求沿用原有主备排序。Gemini 请求失败时进入现有回退链，非 Gemini 条目收到截图；
文本阶段不带视频。视频每个播放秒对应一个截图索引，输出仍由索引映射到真实采集时间。
现有录制分段方式不变。macOS HEVC 与 Windows HEVC / H.264 能否由目标 Gemini 接口解码
要分别验证；Linux 现有截图路径无原始视频分段。

验收使用匿名 HTTP 夹具验证模型列表和视频请求，使用匿名 Go 夹具验证主备媒体选择、
索引映射、样本覆盖和路径约束，并用 macOS 原生匿名分段验证上传候选字节与录制文件一致。
真实 Gemini 响应单独验收。回退可撤销提交，无需数据库迁移；先从路由和设置中移除 Gemini 服务。
