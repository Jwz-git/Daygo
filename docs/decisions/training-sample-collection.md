# 本地训练样本采集与审阅

2026-10-16，用户授权在独立功能分支实现。归属 timeline / providers / data / preferences。

## 决定

增加默认关闭、仅本次运行有效的采集会话，限定截止时间、样本数量和磁盘预算。
采集转录与卡片实际 Provider 请求及成功响应；候选只表示协议层成功，不能冒充人工标签或生产事务成功。
独立采集接口，不向 llm_calls、普通日志或遥测加入正文。失败请求仅计数，不保存失败正文；只有纠错提示、缺少完整证据的后续请求不采集。

样本包保存在应用数据目录的 training 子目录，文件存取归 internal/storage，无业务 schema 迁移。
宿主持有唯一写入 / 捕获锁；有界队列由分析生命周期拥有，退出可丢弃未写队列并计数，不阻断分析。
原始输入不可编辑；首版敏感样本通过拒绝与删除处理，不宣称自动脱敏。审核编辑仅修改标签；重新标注撤销旧审核。
图片已由 Media 解码，复制实际请求字节；不重新读取分段或数据库拼装历史上下文。

本地 Wails 绑定提供开启、停止、列表、预览、审核、删除、教师重标注、导出；不开放 HTTP 监听或第二写连接。
教师调用必须由用户逐样本指定已配置 Provider / 模型及确认发送，单次请求、不回退、不修改正式时间线。
导出只包含隐私与质量均已确认且结构合法的样本，保留来源分组；图片及文本均属于待人工审阅的敏感材料。
导出是本地文件操作，不自动上传。不得将导出包提交 Git。

## 第一版边界与验收

以匿名夹具验证默认零采集、授权时段、请求快照、去重、预算、采集故障隔离、审核撤销、拒绝导出、媒体配对和路径限制。
记录实际图片摘要、提示词 / Schema 摘要、代码版本、模型、请求限制、会话和来源组。
按整个来源组分割训练 / 验证 / 测试，导出不随机拆样本。首次采用整安装来源组，宁可粒度粗也不把关联窗口拆开。
输出 Qwen conversations + images 格式，并保留完整审计样本。训练加载、50–100 条人工样本和真机日常闭环另行验收。
此决策允许明确授权的本地样本正文保存，不改变默认隐私规则；原数据清理不会自动删除训练副本，界面明确告知。

## 回退

停用采集，退出新增分支即可；无数据库迁移。训练目录独立保留，可在审阅页面删除样本。
已导出的包为独立副本，删除源样本不会撤销导出文件。
