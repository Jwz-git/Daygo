# 时间线自动改写保留人工输入

状态：2026-10-05 已决定；实现与验证见 [timeline 执行册](../modules/timeline.md#验证记录)。

## 决定

自动批次、重试、整日重分析与空闲短路不能删除、扩展或覆盖已有人工卡片。
人工卡片包括编辑过分类 / 标题 / 摘要 / 详情的卡片，以及仍有审阅或评分的卡片。
保留原 ID、时间范围、内容与反馈；模型输出扣除这些时间范围后，只落库剩余区间。
人工删除也留下受保护的时间范围，自动分析不能把它重新生成出来。保护与改写在同一
SQLite 写事务内判断，因此生成过程中发生的编辑、审阅或删除也被保护。

v23 新增 `timeline_cards.is_user_edited`。四种编辑及人工删除在原写事务内置 1。
审阅 / 评分保护由对应表是否仍有记录判断；撤销反馈后，没有编辑标记的卡片可再次自动改写。
不把审阅从旧卡自动迁到更长的新卡：用户只审阅过旧区间，新增分钟必须重新审阅。

旧 schema 没有人工编辑来源，时间戳也不能可靠区分同秒编辑与自动更新。迁移将所有旧的
存活卡片标记为受保护，以保留可能已存在的人工输入；不猜测哪些行曾被编辑。
旧的软删除行保持 0，避免已被自动替换的旧版本遮住现有卡片；因此迁移前的人工删除
无法可靠恢复保护。新卡默认 0，自动分析可继续融合它们。

用户明确执行单卡「重新生成」仍走显式替换契约，可以替换人工卡片并使旧卡反馈退出统计。
自动 / 批次重处理使用 `ReplaceGeneratedCardsInRange`，显式单卡替换使用原
`ReplaceCardsInRange`；两者不可互换。该区别不增加 Wails 绑定或改动用户负载。

## 裁剪与边界

保留卡片优先于 AI 的 15 分钟切分偏好；扣除人工区间后可能留下短片段。
新片段重新计算逻辑日与边界，结构化时间点 / 分心区间裁到片段内；旧卡内容与媒体不动。
裁剪后的新片段不能复用覆盖原整段的视频文件。模型文本仍是该次生成文本，不声称经过二次生成。

## 验证与回退

匿名夹具覆盖连续两批、独立编辑 / 审阅 / 评分 / 删除、撤销反馈、多个受保护区间、生成时编辑、
空闲短路、旧库升级与重启读回。真实 Provider / Wails 闭环另记，自动化不提升 G-loop 验收。
v23 已迁移后不能直接运行只接受旧 schema 的版本；回退须停止宿主并恢复升级前备份，
同时保留升级后数据库副本。禁止在用户数据库上试验降级。
